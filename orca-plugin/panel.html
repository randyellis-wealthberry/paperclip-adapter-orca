Paperclip

Run Paperclip agents in Orca worktrees.

  1. Start Paperclip
    In a terminal, run npx paperclipai run.
  2. Connect this repo
    Types the installer into this worktree's terminal. Check it's a shell prompt, then press Enter. Each step prints ✔ or ✘; fix any ✘ and run it again.

  3. Create the agent
    The installer opens Paperclip's new-agent page. Finish setup, then on the agent's Configuration tab pick an Orca repo and turn on the heartbeat.
  4. Assign an issue
    A pc-<ISSUE> worktree appears here with the agent working in its terminal, and Orca notifies you that Paperclip is connected. Approve by moving the card to Completed; request changes by moving it back to In progress with a comment.
